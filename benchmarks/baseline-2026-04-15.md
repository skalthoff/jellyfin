# Porcupine Baseline Benchmarks — 2026-04-15

Database: 500k tracks, 50k albums, 5k artists, 500 genres, 3 users
Seeding time: 189.8s
Platform: macOS Darwin 25.4.0, .NET 10.0, SQLite

## Query Results (median of 3 runs)

| Query | Time | Results |
|---|---|---|
| Album listing (400 items, sorted by name) | 19.8ms | 400 |
| Album listing + COUNT (Jellyfin default) | 23.2ms | 50,400 |
| Albums by artist (ItemValues join) | 32.7ms | 10 |
| Tracks by artist (ItemValues join) | 502.7ms | 100 |
| Artist listing (400 items) | 3.0ms | 400 |
| Recently played tracks (UserData join) | 230.7ms | 50 |
| Search 'rock' across all music types | 119.5ms | 0 |
| Tracks in album (by ParentId) | 0.7ms | 10 |

## Worst Offenders

1. **Tracks by artist: 502.7ms** — correlated subquery through ItemValues→ItemValuesMap→BaseItems, no index on ItemValueMap(ItemId)
2. **Recently played: 230.7ms** — UserData join loading all users, no user-scoped filtering
3. **Search: 119.5ms** — LIKE scan on CleanName without covering index
4. **Albums by artist: 32.7ms** — same ItemValues join, smaller result set
5. **Album listing + COUNT: 23.2ms** — COUNT(*) before pagination
